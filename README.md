# Windows Island

Una Dynamic Island per Windows.

Una pillola nera in alto al centro dello schermo che si apre quando ci passi sopra con il mouse: musica, calendario, timer e file sempre a portata di mano.

## ⬇️ Download

**[Scarica l'ultima versione](https://github.com/Casellus/Winotch/releases/latest)**: apri la pagina e clicca su `WindowsIsland-Setup-x.x.x.exe`.

Poi apri il file scaricato e segui l'installazione. Non servono permessi da amministratore.

> **"Windows ha protetto il PC"?** Succede perché l'app non ha una firma digitale a pagamento. Clicca **Ulteriori informazioni** → **Esegui comunque**.
> Alcuni antivirus o browser potrebbero segnalarla per lo stesso motivo.

Una volta installata, l'app **si aggiorna da sola**: quando esce una nuova versione ricevi una notifica e la installi con un clic.

## Cosa fa

**🎵 Musica**
- Copertina, titolo, artista e logo dell'app (Spotify, YouTube, Apple Music…)
- Play/pausa, avanti, indietro, casuale, ripeti
- Barra di avanzamento trascinabile
- Visualizer che segue davvero l'audio
- Bagliore con i colori della copertina
- Anteprima del brano quando cambia canzone

**⏱️ Timer e cronometro**
- Avvio rapido (1, 5, 10, 25 minuti…)
- Il conto alla rovescia resta visibile nell'isola chiusa, come le Live Activity dell'iPhone

**📅 Calendario**: ora, data e giorni della settimana.

**📂 Shelf**: trascina un file sull'isola per tenerlo lì, poi trascinalo fuori dove ti serve.

**🔊 Volume**: slider del volume di sistema, con la rotellina del mouse e il muto.

**🎨 Personalizzazione**
- Dimensione, colore e arrotondamento dell'isola
- Colore d'accento
- Scelta del monitor
- Si nasconde con giochi e video a schermo intero
- Si avvia con Windows

## Requisiti

Windows 10 (versione 2004 o successiva) oppure Windows 11, a 64 bit.

## Disinstallare

**Impostazioni di Windows → App → App installate → Windows Island → Disinstalla.**
